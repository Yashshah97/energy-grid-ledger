# Usage

```python
import energy_grid_ledger
```

Each module is self-contained; see docstrings for the API:

- `energy_grid_ledger.ledgers` — Implementation of the append-only ledger
- `energy_grid_ledger.events` — Representation of individual events within the ledger
- `energy_grid_ledger.hash_chains` — Hash-chained log implementation
- `energy_grid_ledger.tests_test_ledgers` — Unit tests for the ledger functionality
- `energy_grid_ledger.utils_hashing` — Utility functions for hashing and cryptographic operations
- `energy_grid_ledger.core` — main domain logic and public entry points
